# MotionLab Zero-Dependency

MotionLab is a single-file, browser-based motion editor. Open `index.html` in a current browser—there is no install, server, package manifest, or external asset.

It supports creating rectangles, ellipses, lines, text, and imported images; selecting and dragging objects; editing transform and appearance properties; layers; keyframes; timeline playback; undo/redo; local browser saves; JSON project export; and JSON project import.

## Run

Open `index.html` in a modern desktop browser.

## Limits

The export is a portable MotionLab JSON project, not a rendered MP4 or GIF. Imported images are embedded in exported projects; very large images will make the exported JSON larger. Confirm that the starter UI was created during the hackathon window before submitting under the event's new-code rule.
